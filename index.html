GenAI Chatbot Exploration

An interactive generative AI chatbot that leverages Python on the backend to seamlessly bridge intuitive chat interfaces with state-of-the-art machine learning APIs. The project demonstrates end-to-end AI integration — from user input handling and prompt engineering to real-time streaming responses and multi-turn context window management.

Project Overview

🧠 Core AI Engine

Integrates OpenAI GPT, Google Gemini & Anthropic Claude via a unified Python abstraction layer with dynamic model switching at runtime.

⚡ Backend Architecture

Flask REST server with async streaming, WebSocket real-time updates, rate limiting, and full conversation session management.

🎨 Frontend Interface

Responsive HTML/CSS/JS chat UI with markdown rendering, code syntax highlighting, animated typing indicators, and mobile-first design.

🔧 Prompt Engineering

Custom system prompt design, multi-turn history injection, and configurable temperature & token controls exposed through the UI panel.

Key Features & Highlights
  • Demonstrates deep interest in Generative AI — transformer models, tokenisation, embedding-based retrieval and prompt chaining
  • Multi-provider API integration (OpenAI, Gemini, Anthropic) through a single unified Python wrapper — swap models with one config change
  • Real-time streaming responses via WebSocket — messages appear token-by-token exactly like native AI applications
  • Full multi-turn conversation memory with sliding context window and smart history truncation to stay within token limits
  • Markdown & code block rendering with Prism.js syntax highlighting — model responses look polished and readable
  • Configurable system prompts, temperature, and max-token controls exposed via a collapsible settings panel in the UI
  • Fully mobile-responsive layout — works perfectly across all screen sizes from 320px phones to ultrawide desktops
  • Environment-variable based API key management for secure, production-ready deployment — no secrets in source code
